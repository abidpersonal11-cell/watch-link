# Watch Link — এক লিংকে ক্লিক করলে ভিডিও দেখা

## কীভাবে কাজ করে
- **`/` (রুট লিংক)** — এটাই আপনি সবাইকে পাঠাবেন। কেউ ক্লিক করে **Start** চাপলে ব্রাউজার তার কাছে ক্যামেরা/মাইক্রোফোনের অনুমতি চাইবে। অনুমতি দিলে তার ভিডিও স্ট্রিমিং শুরু হয়ে যাবে।
- **`/admin.html`** — এটা আপনার প্রাইভেট ড্যাশবোর্ড। এখানে সিক্রেট কী দিয়ে ঢুকলে যত visitor বর্তমানে সংযুক্ত আছে, সবার ভিডিও একসাথে গ্রিডে দেখা যাবে।
- এটা **এক-মুখী**: visitor শুধু ভিডিও পাঠায়, আপনার ভিডিও/অডিও তার কাছে যায় না। visitor আপনাকে দেখবে না।
- একই লিংক বারবার ব্যবহারযোগ্য — প্রতিবার নতুন লিংক জেনারেট করার দরকার নেই।

## লোকালি রান করা

```bash
cd watch-link
npm install
npm start
```

- Visitor লিংক: `http://localhost:3000/`
- Admin ড্যাশবোর্ড: `http://localhost:3000/admin.html`

ডিফল্ট সিক্রেট কী হলো `change-this-secret-key`। এটা অবশ্যই বদলে নিন — রান করার আগে:

```bash
export ADMIN_KEY="আপনার-নিজের-শক্তিশালী-কী"
npm start
```

## ইন্টারনেটে ডিপ্লয় করা

ক্যামেরা অ্যাক্সেসের জন্য HTTPS আবশ্যক (localhost বাদে)। ফ্রি-টায়ার অপশন:
- **Render.com**, **Railway.app**, বা **Fly.io** — এগুলো অটোমেটিক HTTPS দেয়।
- ডিপ্লয় করার সময় Environment Variables-এ `ADMIN_KEY` সেট করে দিন (হোস্টিং প্যানেল থেকে)।

ডিপ্লয়ের পর:
- Visitor লিংক শেয়ার করবেন: `https://your-app.onrender.com/`
- আপনি নিজে দেখবেন: `https://your-app.onrender.com/admin.html`

## গুরুত্বপূর্ণ বিষয়

- **সম্মতি**: visitor নিজে Start চেপে ব্রাউজারের পারমিশন পপআপে সম্মতি দিচ্ছে বলেই এটা স্বচ্ছ একটা সিস্টেম — কেউ না জেনে দেখা যাচ্ছে না। কাউকে না জানিয়ে গোপনে দেখার জন্য এটা ব্যবহার করা ঠিক না, এবং আইনগতভাবেও ঝুঁকিপূর্ণ হতে পারে।
- **Admin কী গোপন রাখুন** — এই কী যার কাছে থাকবে সেই সব visitor-এর ভিডিও দেখতে পারবে। `/admin.html` লিংক কাউকে শেয়ার করবেন না।
- **একাধিক visitor** — একসাথে অনেকে লিংকে ক্লিক করলে সবার ভিডিও ড্যাশবোর্ডে আলাদা আলাদা বক্সে দেখা যাবে।
- বর্তমানে কোনো রেকর্ডিং ফিচার নেই — শুধু লাইভ দেখা যায়। রেকর্ড করার দরকার হলে জানাবেন, যোগ করে দেওয়া যাবে।
